# clue-technical-task

This repo holds the e2e Playwright tests for https://opensource-demo.orangehrmlive.com

## Set up

You will need a .env file at the project root which contains the admin credentials. Then run

`npm install`

`npx playwright install`

## Running the tests 

To run the tests:

`npm run test`

To run the tests in UI mode:

`npm run test-ui`
